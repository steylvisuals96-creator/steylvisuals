# steylvisuals

Statische website (`index.html`, `images/`, `logo/`, `videos/`) voor Steyl Visuals.

## Skills

Project-skills staan in `.claude/skills/` en laden automatisch:

- `watch` — video's bekijken (URL of lokaal bestand). Vereist `ffmpeg` en `yt-dlp`
  (macOS: `brew install ffmpeg yt-dlp`). Bron: bradautomates/claude-video.
- GSAP (officieel, greensock/gsap-skills): `gsap-core`, `gsap-scrolltrigger`,
  `gsap-timeline`, `gsap-plugins`, `gsap-utils`, `gsap-react`, `gsap-frameworks`,
  `gsap-performance`.
- `motion-design` — animatieprincipes (LottieFiles/motion-design-skill).
- Uit freshtechbro/claudedesignskills: `motion-framer`, `locomotive-scroll`,
  `scroll-reveal-libraries`, `modern-web-design`, `threejs-webgl`, `react-three-fiber`.
